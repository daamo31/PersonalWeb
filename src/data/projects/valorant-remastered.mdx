## Overview

Valorant Remastered is a website that showcases the Valorant game. It's built with TypeScript, React, and GSAP.

## Tech Stack

- TypeScript
- React
- GSAP

Its a copy of a popular Awwwards website. I built this for fun and to learn about GSAP. But for Valorant.
